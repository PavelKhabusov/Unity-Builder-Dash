ubd CLI

The same build, from one command

If the dashboard is open, ubd hands the build to it over a local API — it shows up in the window like any other. If not, a headless runner builds with the same code.

  • --wait streams the log and exits with the build result.
  • --install <device> — adb serial or iOS device name, installed right after the build.
  • --scripts-only, --aab, --no-increment — the same toggles as the toolbar.
  • --dry-run prints the plan and who would run it. Every command takes --json.

For agents

Built to be driven by an agent

A CLI with exit codes and --json, and a localhost HTTP API on 127.0.0.1:47816 that describes itself at /commands.json. Full rules in AGENTS.md.

# projects, state and logs
./ubd projects
./ubd status --json
./ubd log --tail 50          # or -f to follow
./ubd history 10
./ubd devices
./ubd ios-status            # Mac reachable over SSH? battery?

# builds
./ubd build ARViewer ios --dry-run
./ubd build ARViewer ios --wait
./ubd build MyGame android --scripts-only --install R58M123ABC
./ubd build ARViewer ios --ios-action xcode
./ubd cancel
GET  /health          → {ok, app, owner: gui|headless, pid}
GET  /commands.json   → command manifest for agents
GET  /status · /projects · /log?tail=N · /history?n=N
POST /build           {project, target, scripts_only?, aab?, increment?, install?, ios_action?}
                      → 200 {ok, log_path, status} · 400 bad request · 409 busy
POST /cancel

# port: agent_api_port in config.json or UBD_API_PORT · localhost only
0ok — with --wait, the build succeeded
1build failed or was cancelled; ios-status: Mac unreachable
2bad arguments, unknown project or target
3busy — a Unity build is already running
4GUI is running without the agent API (old version) — restart it
5API error

One Unity build per machine

ubd build refuses with exit code 3 while the dashboard or a headless runner is building, while any Unity -batchmode process runs, or while the target project is open in the Editor. Agents wait with ubd status instead of running out of memory.

Install

Clone, configure, build

Python 3.10+, GTK4 and Libadwaita, a Unity Editor with Android/iOS support, and adb. On first launch Settings opens and finds your Unity Editor.

# Arch:   sudo pacman -S python-gobject gtk4 libadwaita android-tools
# Ubuntu: sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 adb
$ git clone https://github.com/PavelKhabusov/Unity-Builder-Dash.git
$ cd Unity-Builder-Dash
$ cp config.example.json config.json
$ ./install.sh   # GNOME launcher entry — or just ./build.py
